## `$ whoami`

Just a guy doing Web3 security stuff, operating-system stuff, red teaming, reverse engineering, and building some crazy business.

- 🔐 Web and application penetration testing, security research, and offensive security.
- ⛓️ Exploring smart contracts, Ethereum, and Web3 security.
- ⚙️ Interested in operating systems, low-level internals, and reverse engineering.
- 🐧 I love experimenting with Linux, especially Arch.
- 🧪 CTFs, hackathons, hands-on labs, and building tools for problems I run into.
- 🚀 Building things behind the scenes. Some ideas are better revealed when they're ready.

My interests sit at the intersection of **security, systems engineering, and building products**.
