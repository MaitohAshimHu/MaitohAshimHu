## `$ whoami`

I'm Ashim. I do security stuff, build software, mess around with Linux, and occasionally get distracted by an idea that turns into an entire project.

Currently interested in:

- 🔴 **Security** — web pentesting, red teaming, reconnaissance, and figuring out why someone's application does something it absolutely shouldn't.
- ⛓️ **Web3** — Solidity, smart contracts, Ethereum, and learning to find bugs before someone finds them the expensive way.
- ⚙️ **Systems** — Linux, operating systems, reverse engineering, and going down rabbit holes I probably didn't need to open.
- 🤖 **AI** — mostly interested in making it do useful things rather than adding a chatbot to everything.
- 🚀 **Business** — building stuff through [Fortified Developments](https://fortidev.site). More building, less talking about building.

I use Arch, do CTFs, build tools when existing ones annoy me, and have a growing collection of repos that started with *"wait, what if I made this?"*
